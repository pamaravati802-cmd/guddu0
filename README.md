## 🚀 How to Run Locally

Simply double-click **`index.html`** or right-click and choose **Open with Google Chrome** (or Edge/Safari/Firefox).

Or run a local static server if preferred:
```bash
npx serve .
# or
python -m http.server 8000
```

## 🌐 How to Push to GitHub & Make Live on GitHub Pages

### Step 1: Push this repository to GitHub

Open PowerShell or Command Prompt in this folder (`c:\Users\Prajwal\Downloads\guddu`) and run:

```bash
git push -u origin main
```

> **Note on Authentication:**
> When prompted for your GitHub password:
> 1. Use your **GitHub Personal Access Token (PAT)** (not your regular GitHub password, as GitHub requires a token for git over HTTPS).
> 2. To generate a token in 30 seconds: Go to [GitHub Token Settings](https://github.com/settings/tokens) → Click **Generate new token (classic)** → Check the `repo` scope → Click **Generate token** → Copy and paste it when git prompts for Password.

### Step 2: Make It Live (Free GitHub Pages)

1. Go to your repository on GitHub: `https://github.com/pamaravati802-cmd/guddu0`
2. Click **Settings** (tab at the top right).
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment > Branch**:
   - Select **`main`** branch.
   - Select folder **`/ (root)`**.
   - Click **Save**.
5. Wait 30–60 seconds, refresh the page, and GitHub will display your live website link:
   **`https://pamaravati802-cmd.github.io/guddu0/`**
6. Copy that link and send it to Guddu on WhatsApp or Instagram! ❤️
